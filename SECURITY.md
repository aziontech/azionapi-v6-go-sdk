# Security Policy

## Supported Versions

This SDK is auto-generated from Azion's public API specifications. Only the
latest released version is supported with security updates. Please ensure you
are using the most recent release before reporting an issue.

Releases are published at
https://github.com/aziontech/azionapi-v6-go-sdk/releases

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them privately through GitHub Security Advisories:

1. Open https://github.com/aziontech/azionapi-v6-go-sdk/security/advisories/new
2. Fill out the vulnerability report form
3. Submit the report

Alternatively, you can reach the Azion security team at security@azion.com.

Please include as much of the following as you can:

- A description of the vulnerability and its impact
- The affected SDK version and Go version
- Steps to reproduce, or a proof-of-concept
- Any suggested mitigation

## Disclosure Timeline

- **Acknowledgement:** within 3 business days of your report
- **Initial assessment:** within 10 business days, including severity and
  expected remediation window
- **Status updates:** at least every 15 days until resolution
- **Public disclosure:** coordinated with the reporter after a fix is released,
  via a GitHub Security Advisory at
  https://github.com/aziontech/azionapi-v6-go-sdk/security/advisories

We ask that you keep the report confidential until a fix has been published.
Azion does not currently operate a paid bug bounty program, but we credit
reporters in the published advisory unless you ask otherwise.
